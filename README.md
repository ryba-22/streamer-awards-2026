# The Streamer Awards 2026 — unofficial schedule

Single-page static site hosted on GitHub Pages. No build step is required for the website.

## Performance

- 152 locally optimized WebP portraits in assets/nominees (maximum 480 px wide, 640 px high).
- Original source: https://thestreamerawards.com/nominees
- No photos requested on initial page load. Opening an award inserts the cards and IntersectionObserver loads thumbnails only near the viewport.
- Official original JPEG is a fallback if a local thumbnail fails.
- Mobile hero is compact so the award schedule appears quickly.
